# maclm-agent — Дорожная карта

**Revision 4**
**Изменения Rev 4:** после v0.3 вставлены v0.4 Workspace (переработка интерфейса, проекты, фоновые сессии, инспектор, диффы, чекпоинты) и v0.4.x Десктоп-питомец, затем v0.5 Skills. Shell → v0.6, AppleScript → v0.7, Native API → v0.8, Docker → v0.9, MLX → v0.10, UX polish → v0.11. Причина порядка: диффы в подтверждениях и чекпоинты — это безопасность, и они должны появиться до развития уже существующего базового `run_shell` в фазе v0.6.
**Изменения Rev 3:** Security hardening поднята на v0.3, введён трек системной интеграции.

---

## Принцип

Каждый шаг завершается **работающим приложением**, атомарным коммитом и тегом версии. Следующий шаг не начинается, пока предыдущий не закрыт. Промпты для Codex — самодостаточные, с полным контекстом внутри. Порядок фаз пересматривается по реальному трению в использовании, а не только по технической последовательности.

## v0.5 — Skills ⏳ не начато

`SKILL.md`, allowlist и хэши, опт-ин источники `~/.claude/skills` / `~/.codex/skills`, `@`-палитра в композере, «создать навык из сессии». Детальный дизайн и промпты — после закрытия v0.4.x (SPEC Rev 5).

## v0.6 — Shell / Terminal ⏳ не начато

Базовый `run_shell` уже существует: `/bin/zsh -c`, таймаут 30 с, отмена, stdout/stderr/exitCode/timedOut, всегда dangerous, без path-политик. Завершение группы, ограниченное ожидание pipe и маршрутизация файловых операций в описании выполнены в v0.3.6. В v0.4.7.1 добавлены начало/хвост по 8 КиБ каждого потока и жёсткий предел 32 МиБ с остановкой группы. Фаза развивает его: `Process`, потоковый вывод, таймауты, отмена, рабочая директория = папка проекта. Режимы `direct` (структурированный) и `shell` (универсальный, всегда `dangerous`). «Открыть в Terminal.app». Принуждение по измерению `command`.
