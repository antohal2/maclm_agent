# Шаг 4.8 — панель питомца

## 1. Арт и ресурсы

Встроенных `bronya/pet.json` и `bronya/spritesheet.png` нет: используется Canvas-плейсхолдер 64×64. Все восемь состояний различаются символами и движением, не только цветом. Новых зависимостей нет.

`project.yml` включает исходники рекурсивно. Для `Resources/Pets` добавлен отдельный folder resource с сохранением иерархии (`Contents/Resources/Pets/bronya`); этот путь исключён из обычного source entry. Добавить арт позже можно без изменения Swift-кода. Читаются только два фиксированных файла. Повреждённый арт отвергается целиком, причина записывается в системный лог, затем используется плейсхолдер.

JSON читается ограниченно (64 КБ), изображение — до 8 МБ. Тип PNG определяется ImageIO. Свойства размеров проверяются до `CGImageSourceCreateImageAtIndex`; также исключены отрицательные/переполняющие индексы строк и заведомо огромные листы (свыше 16 777 216 пикселей). Кадры нарезаются однократно. Неизвестные ключи JSON игнорируются; типы, неизвестные состояния, дубликаты и диапазоны проверяются.

## 2. CPU

Отдельный временный стенд использовал текущие `PetView`, `PetPlaceholder`, `PetPanel`, `PetRuntime`, без LLM, сети и рабочего SwiftData-хранилища. Масштаб ×2; сборка Swift 6, без оптимизации. Среднее по разнице CPU time процесса за 20 секунд:

| Состояние | Частота плейсхолдера | CPU |
|---|---:|---:|
| idle | 3 fps | 0,65% |
| running | 10 fps | 5,95% |
| скрытая панель | TimelineView paused | 0,10% |

Activity Monitor: около 0,7% в idle и 6,1% в running. Это стоимость рендера в стенде, **не замер всего приложения с работающей моделью**. CPU в idle соответствует ориентиру ~1%. Полная нагрузка приложения зависит от сессий и локального сервера.

## 3. Мониторы, Spaces и fullscreen

Панель: nonactivating + borderless, transparent, floating, без shadow, `canJoinAllSpaces` + `fullScreenAuxiliary`, не скрывается при деактивации. `canBecomeKey` и `canBecomeMain` возвращают false. Анимация при невидимости/окклюзии приостанавливается; Reduce Motion отслеживается через уведомления NSWorkspace.

Юнит-тесты проверяют отрицательные координаты второго монитора, выход за экран, частично скрытую панель и NaN; позиция вне любой visibleFrame возвращается в угол главного экрана, отступ 24 pt. При изменении конфигурации дисплеев позиция проверяется повторно. Тест контроллера проверяет реальные флаги NSPanel, show/hide, масштабы и reset позиции.

Физическая конфигурация нескольких мониторов и переходы между полноэкранными Spaces вручную не проверены. Флаги окна и геометрические тесты не заменяют эту проверку.

## 4. Клик и интеграция

Источник статуса — существующий `SessionRunnerRegistry.aggregate`, без изменений реестра, AgentLoop и разрешений. Приоритет точно соответствует коду: needsApproval > failed > toolRunning > running > ready > idle. UUID выбирается первым из уже отсортированного списка. Клик выбирает беседу через `ChatViewModel.selectConversation` и вызывает существующий `SceneActions.openMainWindow()`; этот же механизм используется меню/уведомлениями. При idle только открывается окно. Выбор беседы снимает unread обычным существующим путём. Названия, ответы и аргументы на панели не отображаются.

Короткий клик отличается от drag порогом 3 pt; позиция сохраняется после drag. Перетаскивание проверено на временном стенде; доступность возвращала состояния idle, running и drag.

`/pet` перехватывается в общем `ChatViewModel.send` до создания сообщений/запуска модели, очищает draft и переключает общий `AppSettings.petEnabled`, в том числе без доступной модели и во время генерации. `/PET` и `/pet please` не являются командами. Общий ComposerView используется и в окне, и в popover. Правый клик menu bar открывает пункт show/hide, левый сохраняет popover. Вкладка «Питомец» добавлена после «Буфер обмена», перед «Внешний вид»; всего шесть вкладок.

Более поздние пузырь, Quick Chat, импорт и подтверждения из питомца не реализованы. SwiftData-схема не менялась.

## 5. Ручная проверка

- `/pet` из главного окна и popover: draft исчезает, сообщений не добавляется; повторная команда скрывает питомца.
- Правый клик status item: show/hide; левый клик по-прежнему открывает popover.
- Масштабы ×1/×2/×3, перетаскивание без активации панели, сохранение после перезапуска, «Вернуть в угол экрана».
- Фоновая сессия: running/toolRunning/needsApproval/ready/failed; клик открывает беседу нужного приоритета.
- Пять минут непрерывного idle дают sleep; активность сбрасывает отсчёт, drag временно перекрывает статус.
- Включить/выключить Reduce Motion: статичная поза/возобновление анимации. Проверить VoiceOver без перехвата клавиатурного фокуса.
- Несколько мониторов, отключение монитора, разные Spaces и полноэкранное приложение; проверить присутствие питомца и восстановление координат.
