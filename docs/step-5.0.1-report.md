# Шаг 5.0.1 — исключение метаданных macOS из навыков

Дата: 2026-10-21 (Asia/Novosibirsk). Версия: `v0.5.0.1`, база: `v0.5.0`.

Единая функция `SkillFilePolicy.isIgnored` исключает точное имя `.DS_Store`
и имена с префиксом `._` на любой глубине. Сканер проверяет имя до `stat`
и открытия: такие записи, включая симлинки, FIFO и каталоги, не обходятся,
не читаются и не попадают в лимиты, манифест хэша и список файлов Settings.
`SkillFileIO.readFile` использует ту же функцию для отказа по любому компоненту
пути; её должен использовать будущий `read_skill_file` шага 5.2.
SPEC §15.4 дополнен этим исключением. Версия проекта — `0.5.0.1`.

Для навыков, включённых в v0.5.0 с такими файлами, хэш изменится один раз:
состояние станет `needsReconfirm`. Миграция не добавлялась.

Проверки:

- `make generate`, `make build`, `make test` — успешно.
- 319 тестов: 0 ошибок, 4 пропуска из-за отсутствующих локальных снимков.
  Девять новых тестов покрывают исключения, лимиты, специальные файлы,
  отказ чтения, похожие имена, сохранение доверия и старый хэш.
- Новых предупреждений нет; остаются предупреждения в неизменённых
  `ToolCallCard.swift`, `ClipboardActionRunnerTests.swift` и AppIntents.
- SwiftFormat проходит; SwiftLint strict изменённых файлов — 0 нарушений.
  Полный `make lint` останавливается на двух прежних длинных строках:
  `PetSettingsView.swift:13` и `PetLibraryTests.swift:36`.
- `git diff --check` — без замечаний.

Ручной сценарий Finder → смена вида → Rescan **не подтверждён**:
UI-инструмент дважды вернул `Sky Computer Use native pipe closed before response`,
включая попытку после сброса. Изолированная in-memory сборка запускалась
и остановлена; тестовые навыки в пользовательское хранилище не добавлялись.
Сохранение `enabled` при добавлении, изменении и удалении `.DS_Store`/`._foo`
в корне и подпапке, а также при замене их симлинками подтверждено тестом store.
