# Пользовательские питомцы

Питомец — только данные: `pet.json` и `spritesheet.png`. Приложение не запускает
скрипты, не загружает код и не обращается к сети при импорте.

## Формат

Пример контракта из шага 4.8 (для своего питомца замените `scout` и имя):

```json
{
  "version": 1,
  "id": "scout",
  "name": "Скаут",
  "frameSize": 64,
  "columns": 8,
  "rows": [{ "row": 0, "state": "idle", "frames": 6, "fps": 6, "loop": true }],
  "reduceMotionFrame": 0
}
```

- `version`: только 1; `frameSize`: только 64.
- `id`: текущий контракт валидатора `^[a-z0-9-]{1,40}$`. Только ASCII, маленькие
  латинские буквы, цифры и дефис; без точек, слешей, пробелов и управляющих символов.
  `scout` зарезервирован; коллизии с установленными проверяются без учёта регистра.
- `name`: от 1 до 40 символов; `columns`: от 1 до 16.
- `rows`: уникальные состояния и индексы строк. `idle` обязателен. Возможные состояния:
  `idle`, `running`, `toolRunning`, `needsApproval`, `ready`, `failed`, `drag`, `sleep`.
  Отсутствующее состояние отображается через `idle`.
- `row`: неотрицательный индекс; `frames`: 1…`columns`; `fps`: 1…30; `loop`: boolean.
- `reduceMotionFrame`: индекс статичного кадра, существующий в каждой описанной строке.
  Неизвестные ключи JSON игнорируются.

Каждый кадр PNG занимает 64×64 пикселя. Размер листа должен быть ровно
`columns × 64` по ширине и `(максимальный row + 1) × 64` по высоте.
Индексы строк задаются JSON; код не требует порядка строк из таблицы SPEC.
PNG проверяется по содержимому, размер и число пикселей проверяются до декодирования:
не более 8 МиБ и 16 777 216 пикселей. JSON — не более 64 КиБ.

## Установка и управление

Подготовьте папку:

```text
my-pet/
  pet.json
  spritesheet.png
```

Откройте «Настройки» → «Питомец» → «Добавить питомца…», выберите одну папку.
Остальные файлы игнорируются и не копируются. Симлинки на обязательные файлы
и папки вместо обычных файлов отвергаются. Уже установленный `id` требует
подтверждения «Заменить питомца?». Импорт выбирает установленного питомца сразу.

Хранилище: `~/Library/Application Support/local.maclm-agent/Pets/<id>/`.
Оно создаётся при первом импорте. Максимум — 50 питомцев, включая неисправные
папки; замена доступна и при достигнутом лимите. Инструменты модели не могут
читать или менять хранилище: оно внутри обязательного block-правила приложения.

В списке доступны миниатюра первого кадра `idle`, имя, `id` и выбор.
«Удалить» требует подтверждения; удаление активного возвращает встроенного.
Симлинк в хранилище удаляется как ссылка, его цель остаётся нетронутой.
«Обновить список» перечитывает папки и показывает неисправные с причиной;
выбрать их нельзя. При запуске и перезагрузке повреждённый или пропавший активный
питомец заменяется встроенным, сохранённый выбор сбрасывается.
Масштаб и положение при выборе сохраняются. Встроенный питомец пока — плейсхолдер.

## Как сделать своего

Подготовьте горизонтальные полоски кадров для каждого состояния в AI-генераторе:
одинаковые ракурс, масштаб и положение, клетки 64×64, однотонный маджента-фон.
Удалите фон во внешнем графическом редакторе, разместите кадры слева направо
в PNG с прозрачностью и заполните строки JSON в соответствии с листом.
Неиспользуемые клетки допустимы; значение `frames` определяет проигрываемые кадры.
Скрипта `tools/assemble_pet.py` в репозитории нет; сборка листа выполняется внешними
средствами. Приложение никакие скрипты питомца не запускает.

## Защита импорта

Открытие `O_NOFOLLOW`, проверка `fstat` и ограниченное чтение идут через один
дескриптор каждого файла. Подмена имени после открытия не меняет источник чтения.
Пути назначения строятся только после проверки `id`. Проверенные байты записываются
в скрытый каталог внутри `Pets`, затем повторно проверяются с диска.
Новая установка использует атомарный `RENAME_EXCL`, замена — `RENAME_SWAP`:
старый каталог остаётся установленным до успешной проверки новой копии.
При отказе до установки старый остаётся целым, временная копия удаляется.
Алерт содержит локализованную причину без полного пути или сырой ошибки;
технические сведения идут в системный лог.

## English

A pet is data only: `pet.json` and `spritesheet.png`. Import one folder in
Settings → Pet → Add pet…; unrelated files are ignored. Frames are 64×64 PNG,
1–16 columns; sheet height is `(max row + 1) × 64`. JSON is limited to 64 KiB,
PNG to 8 MiB and 16,777,216 pixels. `idle` is required. IDs follow the existing
`[a-z0-9-]{1,40}` contract; `scout` is reserved and collisions are case-insensitive.
No scripts run. No symlinks are followed for pet files. At most 50 pets can be
installed. Replacement is confirmed and atomic after disk revalidation.
Refresh marks invalid entries as broken; a missing or invalid active pet falls
back to the built-in Scout (Canvas only if bundled art fails). Model tools cannot access the storage directory.
