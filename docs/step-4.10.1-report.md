# Step 4.10.1 — Scout / Скаут

Встроенный `scout` загружается в PetLibrary через неизменённый PetLoader и PetManifest.validate. Имя и миниатюра в настройках берутся из манифеста. Canvas используется только при ошибке загрузки/валидации, причина логируется через NSLog. Custom и unknown IDs сохраняют прежнюю семантику; старый встроенный выбор мигрирует при чтении настроек с записью в UserDefaults.

Арт — оригинальный персонаж, созданный AI-генератором изображений и собранный в спрайт-лист. Использованы предоставленные пользователем файлы без изменения.

Проверки: `make generate`, `make build`, `make test` прошли. 281 тест, 1 пропущен, 0 ошибок. Production validator проверил ресурс из Bundle.main: 8 строк, 64×64, 8 столбцов, 512×512 PNG, все ожидаемые frames/fps/loop. Тесты проверяют миграцию, custom/unknown IDs, отказ повреждённого встроенного арта с логированием, успешную загрузку без fallback, выбор и перезагрузку. Существующие тесты панели проверяют включение, масштаб и сброс позиции.

В бандле подтверждены `Contents/Resources/Pets/scout/pet.json` и `spritesheet.png`; иерархия сохранена. Валидатор и лимиты не изменены. Новых предупреждений в изменённых файлах нет; остаются прежние предупреждения ClipboardActionRunnerTests (порядок try/await) и AppIntents metadata extraction.

Ручной визуальный прогон свежего запуска и Settings не подтверждён: два обращения к UI завершились `Sky Computer Use native pipe closed before response`. Настройки/пузырь/подтверждения не менялись по поведению.
